
# Join – Kanban Project Management Tool

Join is a web-based project management application inspired by the Kanban methodology. It allows users to organize tasks, track progress, and collaborate through an intuitive and responsive interface.

The application was developed as a group project during the web development bootcamp at Developer Akademie.

## Features

- **Task Management** – Create, edit, and delete tasks with descriptions, due dates, priorities, and assigned contacts.
- **Kanban Board** – Organize tasks across four stages: To Do, In Progress, Await Feedback, and Done.
- **Drag & Drop** – Move tasks between different stages using drag-and-drop functionality.
- **Contact Management** – Create, edit, and manage contacts and assign them to tasks.
- **Task Search** – Quickly find tasks using the integrated search function.
- **Dashboard** – View task statistics, progress, and upcoming deadlines.
- **User Authentication** – Sign up, log in, or explore the application using guest access.
- **Responsive Design** – Adapted for desktop, tablet, and mobile devices.

## Tech Stack

- **HTML5** – Structure and semantic markup
- **CSS3** – Styling and responsive layout
- **JavaScript (Vanilla JS)** – Application logic and interactivity
- **Firebase Realtime Database** – Data storage and synchronization
- **Git & GitHub** – Version control and collaboration

## Getting Started

To run Join locally, follow these steps:

### 1. Clone the repository

```bash
git clone https://github.com/Rel502/Join.git
```

### 2. Open the project directory

```bash
cd Join
```

### 3. Start the application

Open the project in Visual Studio Code and launch `index.html` using the **Live Server** extension.

No additional dependencies or build process are required.

**Note:** The application connects to a Firebase Realtime Database. An active internet connection and appropriate database access are required for full functionality.
